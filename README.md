# 키메라 테일즈

쿼터뷰(아이소메트릭) 필드에서 몬스터를 동료로 얻고, 두 동료를 조합해 더 강한 몬스터를 만들어 가는 실시간 RPG입니다. 그래픽은 모두 캔버스로 직접 그린 자체 제작 아트이며 외부 이미지 파일을 쓰지 않습니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 타입 검사 + 프로덕션 빌드 (dist/)
```

## 조작

| 입력 | 동작 |
| --- | --- |
| 땅 클릭 (누르고 있기) | 이동 |
| 몬스터 클릭 / Tab | 대상 지정 후 자동 공격 |
| 1 | 강타 (마나 8) |
| 2 | 회복의 노래 (마나 14) |
| Q / E | 체력 물약 / 마나 물약 |
| I / P / B / H | 가방 / 동료 / 조합식 / 도움말 |
| Esc | 창 닫기 |

## 게임 구조

- **동료**: 몬스터를 쓰러뜨리면 낮은 확률로 혼석이 나옵니다. 가방에서 혼석을 쓰면 그 몬스터가 동료가 됩니다. 최대 10마리를 보유하고 3마리까지 출전시켜 함께 싸웁니다. 동료도 경험치를 얻어 성장합니다.
- **조합**: 마을의 조합사에게 일정 레벨 이상의 동료 둘을 맡기면 조합식에 따라 상위 단계의 새 몬스터가 태어납니다. 실패하면 비용만 사라지고 재료는 남습니다. 조합식 13개, 몬스터 26종(야생 12종, 보스 1종, 조합 전용 13종)이 있습니다.
- **지역**: 새싹 마을(안전 지대) → 풀잎 들판 → 속삭이는 숲 → 붉은 황야 → 서리 고원(보스). 미니맵의 파란 점이 포탈입니다.
- **마을**: 상인(물약, 귀환 주문서, 무기와 방어구), 치료사(무료 회복), 조합사.
- **저장**: 진행 상황은 브라우저 localStorage에 자동 저장됩니다. 도움말 창에서 초기화할 수 있습니다.

## 코드 구성

| 파일 | 내용 |
| --- | --- |
| `src/data.ts` | 몬스터 종, 조합식, 장비, 지역 정의와 수치 공식 |
| `src/world.ts` | 지역 맵 생성, 충돌, A* 길찾기 |
| `src/game.ts` | 게임 상태, 전투, 동료 AI, 조합, 저장 |
| `src/art.ts` | 캐릭터, 몬스터, 배경 오브젝트를 그리는 절차적 아트 |
| `src/render.ts` | 아이소메트릭 렌더러, 미니맵 |
| `src/ui.ts` | HUD와 창(가방, 동료, 조합, 상점) |
| `src/main.ts` | 입력 처리와 메인 루프 |
