# Roguelike Dong

이 게임은 실시간 탑다운 액션 로그라이크입니다. 죽어도 캐릭터의 스탯은 영구적으로 강해지지 않습니다. 대신 **해금 요소(캐릭터, 아이템, 스킬)가 늘어나고**, 그만큼 런마다 시도할 수 있는 빌드 방향이 넓어집니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 타입 검사 + 프로덕션 빌드 (dist/)
```

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 방향키 | 이동 |
| 마우스 | 조준 |
| 좌클릭 (누르고 있기) | 공격 |
| Space / 우클릭 | 스킬 |
| Esc / P | 일시정지 |

## 게임 구조

- **런**: 방 15개로 이루어집니다. 방은 적 웨이브를 모두 처치하면 클리어됩니다. 5, 10, 15번째 방에는 보스가 나오고, 15번째 보스를 잡으면 클리어입니다.
- **보상**: 방을 클리어할 때마다 카드 3장 중 하나를 고릅니다(아이템 또는 스킬 교체, 체력이 낮으면 회복). 카드는 **해금된 항목에서만** 나옵니다.
- **메타 진행**: 런이 끝나면 누적 기록(처치, 사망, 최고 도달 방, 보스 처치 등)이 갱신되고, 조건을 채운 항목이 해금됩니다. 런을 포기하면 진행 기록은 반영되지만 사망 횟수는 올라가지 않습니다.

## 코드 구조

| 파일 | 역할 |
| --- | --- |
| `src/content.ts` | 캐릭터, 아이템, 스킬 정의와 해금 조건 (콘텐츠 추가는 이 파일에서) |
| `src/meta.ts` | 저장(localStorage), 누적 통계, 해금 판정 |
| `src/game.ts` | 런 시뮬레이션: 플레이어, 적, 투사체, 보스, 보상 생성, 렌더링 |
| `src/ui.ts` | 메뉴, 해금 도감, 보상 선택, 결과 화면 (DOM 오버레이) |
| `src/input.ts` | 키보드/마우스 입력 |
| `src/main.ts` | 화면 전환과 게임 루프 |

새 아이템을 추가하려면 `ITEMS`에 `apply(m)`로 `Mods`를 수정하는 항목을 넣습니다. 새로운 효과가 필요하면 `Mods`에 필드를 추가하고 `game.ts`에서 처리합니다.
