# Roguelike Dong

이 게임은 실시간 탑다운 액션 로그라이크입니다. 죽어도 스탯은 영구적으로 강해지지 않습니다. 대신 **해금 요소(직업, 아이템, 스킬)가 늘어나고**, 그만큼 런마다 시도할 수 있는 빌드 방향이 넓어집니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 타입 검사 + 프로덕션 빌드 (dist/)
npm run build:single  # 호스팅용 페이지 (dist/play.html + app.js + sprite-*.png)
```

`dist/play.html`은 CSS만 인라인한 작은 페이지이고, 게임 코드(`app.js`)와 이미지(`sprite-0.png` 스프라이트 시트, `sprite-1.png` 보스 텍스처)를 같은 폴더에서 상대 경로로 읽습니다. 보스 3D 모델(GLB)은 `app.js` 안에 들어 있습니다. 호스팅 환경의 보안 정책이 fetch를 막아도 모델이 뜨도록, 네트워크 요청 없이 코드 안의 데이터를 직접 디코드해 읽습니다. 호스팅 환경이 문서 골격을 씌워 주는 경우에 맞춰 `<html>`, `<head>`, `<body>` 태그가 없습니다. 브라우저에서 직접 실행할 때는 `npm run dev`나 `npm run preview`를 쓰세요.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 방향키 | 이동 |
| 마우스 | 조준 |
| 좌클릭 (누르고 있기) | 공격 |
| Space / 우클릭 | 스킬 |
| E | 바닥의 장비 장착 (기존 장비는 바닥에 놓임) |
| Esc / P | 일시정지 (장착 장비 확인) |

스킬 쿨타임 감소는 아이템(모래시계)과 장비를 모두 합쳐도 원래 쿨타임의 40%까지만 줄어듭니다.

## 게임 구조

- **런**: 방 15개로 이루어집니다. 방은 적 웨이브를 모두 처치하면 클리어됩니다. 5, 10, 15번째 방에는 보스가 나오고, 15번째 방을 클리어한 뒤 사다리에 오르면 던전 클리어입니다.
- **장비**: 적을 처치하면 낮은 확률로, 일반 방을 클리어하면 30% 확률로 장비가 떨어집니다. 보스 방은 클리어 시 장비가 보장됩니다. 슬롯은 무기, 투구, 갑옷, 신발, 장신구 5개입니다. 빈 슬롯의 장비는 가까이 가면 자동으로 장착되고, 이미 장착한 슬롯은 E로 교체합니다. 장비 근처에 가면 현재 장비와 비교하는 정보 창이 뜹니다. 최대 체력을 올리는 장비는 처음 낄 때만 늘어난 만큼 회복합니다(같은 장비를 다시 껴도 회복하지 않음).
  - 등급: 일반, 고급(옵션 1개), 희귀(옵션 2개), 전설(옵션 3개). 깊은 방일수록 높은 등급이 잘 나오고, 보스는 희귀 이상을 떨어뜨립니다.
  - 방어 수치 a는 받는 피해를 a / (a + 15) 비율만큼 줄입니다.
- **무기 공격**: 장착한 무기를 실제로 휘두릅니다. 베기(검, 단검, 도끼류)는 부채꼴로 휘두르고, 찌르기(레이피어, 창)는 좁고 길게 찌르며, 내려치기(망치, 철퇴, 양날 도끼)는 넓고 느리게 내려쳐 강하게 밀어냅니다. 활은 화살을, 지팡이는 적을 꿰뚫는 마력구를 쏩니다. 주먹(건틀릿)은 찌르기와 같은 좁은 범위를 아주 빠르게 좌우 번갈아 치고, 채찍은 느리지만 찌르기보다 길고 넓게 물결치며 뻗습니다. 베기와 내려치기는 적의 투사체를 쳐냅니다.
  - 단검은 사거리가 가장 짧은 대신 빠르고 치명타 확률 +10%를 기본으로 가집니다. 고유 특징 **연격**: 같은 적을 0.8초 안에 다시 맞힐 때마다 그 적에게 주는 피해가 +12%씩 쌓입니다(최대 5중첩, +60%). 중첩은 적 체력 바 위의 작은 칸으로 보이고, 0.8초 동안 맞히지 않으면 사라집니다.
- **적**: 오크 전사(추적), 오크 주술사(직선 사격), 임프(무리), 초트(돌진), 호박 괴물(대형, 6번 방부터)이 나옵니다. 보스를 쓰러뜨린 뒤에는 일부 적이 플레이어의 전투 방식에 적응합니다(아래 "적의 적응" 참고).
- **출구**: 방을 클리어하면 위쪽에 사다리가 나타납니다. 장비를 정리한 뒤 사다리에 올라서면 다음 방으로 내려갑니다.
- **보상**: 보물 방(3, 5, 8, 10, 13번 방)에는 잠긴 보물 상자가 놓여 있습니다. 방을 클리어하면 잠금이 풀리고, 상자 앞에서 E를 누르면 카드 3장 중 하나를 고릅니다(아이템 또는 스킬 교체, 체력이 낮으면 회복). 상자를 열기 전에는 사다리를 탈 수 없습니다. 보물 방은 위쪽 방 진행도에 금색 테두리로 표시됩니다. 그 밖의 방은 클리어 시 최대 체력의 12%만 회복하고 바로 다음 방으로 넘어갑니다. 카드는 **해금된 항목에서만** 나옵니다.
- **메타 진행**: 런이 끝나면 누적 기록(처치, 사망, 최고 도달 방, 보스 처치 등)이 갱신되고, 조건을 채운 항목이 해금됩니다. 런을 포기하면 진행 기록은 반영되지만 사망 횟수는 올라가지 않습니다.

## 적의 적응

적은 플레이어가 싸우는 방식을 보고 진화합니다. 기록은 런마다 새로 시작합니다.

- **기록**: 방을 클리어할 때마다 그 방에서의 전투를 성향 점수(0~1)로 바꿔 런 누적 점수에 섞습니다(직전 누적과 이번 방을 절반씩). 적이 나와 있는 동안만 기록하고, 전투가 3초보다 짧은 방은 건너뜁니다.
- **단계**: 첫 보스(5번 방)를 쓰러뜨리면 1단계, 두 번째 보스(10번 방)를 쓰러뜨리면 2단계입니다.
  - 1단계: 일반 방 적의 30%가 가장 두드러진 성향 1개에 대응합니다.
  - 2단계: 적의 40%가 두드러진 성향 2개 중 하나에 대응합니다.
  - 보스와 임프는 적응하지 않습니다. 기준 점수를 넘은 성향이 없으면 적응도 없습니다.
- **예고**: 방에 들어갈 때 배너 아래에 "적이 당신의 ○○ 전투에 적응했다"와 대응 이름이 나오고, 오른쪽 위 방 번호 아래에 이번 방의 대응이 표시됩니다. 적응한 적은 발밑에 대응 색의 점선 고리와 머리 위 마름모가 붙습니다. 일시정지 화면의 "적의 적응"에서 성향별 점수 막대와 지금 적용 중인 대응을 볼 수 있습니다.

| 플레이어 성향 | 측정 방법 | 기준 | 적의 대응 | 대처법 |
| --- | --- | --- | --- | --- |
| 근접 위주 | 직접 피해 중 근접 비율 | 0.7 | 가시 피부: 근접으로 때리면 작은 피해(3 + 방 번호/3)를 받음. 무적 시간을 주지 않음 | 원거리, 투척, 포탑, 상태이상 |
| 원거리 위주 | 직접 피해 중 투사체 비율 | 0.7 | 정면 방패: 정면(양쪽 57도)에서 온 투사체를 막음. 방패는 초당 1.6rad로 천천히 플레이어를 향함 | 옆으로 돌아가서 쏘기, 도탄, 근접 |
| 거리 유지형 | (가까운 적과 평균 거리 - 120) / 180 x 움직인 시간 비율 | 0.5 | 예측 사격: 주술사는 예견자로 진화, 초트는 갈 자리로 더 빠르게 돌진, 나머지는 이동 속도 +30% | 발사나 돌진 직전에 방향 꺾기 |
| 제자리 난전형 | 서 있던 시간 비율 | 0.45 | 장판 공격: 3.2~4.4초마다 서 있는 자리에 1초 뒤 터지는 장판 | 자리 옮기기 |
| 원소 위주 | 전체 피해 중 화상, 독 비율 | 0.3 | 원소 저항: 화상과 독 피해 35%, 빙결이 2.5배 빨리 풀림 | 직접 피해 |
| 스킬 의존형 | 6초에 한 번 쓰면 1 | 0.6 | 잠복 폭발: 스킬을 쓰면 0.28초 뒤 그 자리에 0.75초 뒤 터지는 폭발 1~3개 | 스킬 뒤 바로 이동 |

**예견자**는 무작위로 나오지 않고, 거리 유지형에 적응한 오크 주술사가 진화한 모습입니다. 거리를 두다가 멈춰서 보라색 점선 조준선을 보여 준 뒤 쏩니다. 탄은 플레이어가 지금 방향과 속도로 계속 움직였을 때 도착할 자리로 날아갑니다(최대 1.8초 앞까지 예측). 조준선은 발사 직전까지 이동에 맞춰 갱신되므로, 발사 직전에 방향을 꺾거나 멈추면 피할 수 있습니다.

## 보스 2페이즈

보스는 체력이 50% 이하가 되면 1.6초 동안 포효하며(이 동안 무적이고 화상, 독 피해와 단검 연격 중첩도 들어가지 않습니다) 2페이즈로 넘어갑니다. 1페이즈 보스의 체력은 한 번에 큰 피해를 받아도 50% 아래로 내려가지 않으므로 2페이즈를 건너뛸 수 없습니다. 포효할 때 화면의 적 탄이 사라지고 가까이 있던 플레이어는 밀려납니다. 보스 체력 바에는 50% 기준선이 표시되고, 2페이즈에는 이름 뒤에 "분노"가 붙습니다.

- **모습**: 원본 디자인 자체를 바꾼 2페이즈 전용 도트 그림으로 바뀝니다. 원본 픽셀의 명암을 유지한 채 단계별 5색 팔레트(파수꾼 잿불, 군주 공허의 보라, 심연의 왕 핏빛)로 다시 칠하고, 눈처럼 밝은 부분은 빛나는 색으로 바꾸고, 머리 꼭대기를 찾아 픽셀 뿔 두 개를 외곽선과 함께 그려 넣습니다. 3D 모델도 같은 팔레트로 텍스처 자체를 다시 칠하고 머리에 뿔을 붙입니다. 몸집은 약 15% 커집니다.
- **패턴 강화** (1페이즈 패턴을 그대로 강화):

| 1페이즈 | 2페이즈 |
| --- | --- |
| 원형 탄막 | 탄 1.5배, 0.3초 뒤 엇갈린 두 번째 고리 |
| 부채꼴 조준탄 | 탄 +4, 0.22초 간격 3연사(쏠 때마다 다시 조준) |
| 돌진 (군주, 심연의 왕) | 준비 시간 단축, 2연속 돌진, 돌진이 끝날 때마다 원형 탄막 |
| 졸개 소환 (파수꾼) | 5마리 소환과 동시에 원형 탄막 |
| 나선 탄막 (심연의 왕) | 팔 2개에서 4개로, 더 촘촘하고 길게 |
| 공통 | 이동 속도 +25%, 공격 간격 -30% |

패턴은 `src/game.ts`의 `updateBoss`, 팔레트는 `src/rage.ts`의 `RAGE_RAMP`, 도트 뿔은 `src/sprites.ts`의 `buildRage`, 3D 뿔 모양은 `src/boss3d.ts`의 `HORN`에 있습니다.

## 전직과 각성

모든 런은 아무 특성 없는 **모험가**(체력 100, 스킬 없음, 무채색 모습)로 시작합니다. 출정하면 **첫 무기 뽑기**가 열려, 해금된 무기 중 하나가 무작위 등급(일반 70%, 고급 22%, 희귀 7%, 전설 1%)으로 뽑힙니다. 릴을 누르거나 건너뛰기를 누르면 바로 결과가 나오고, 희귀 이상은 빛줄기 연출이, 전설은 화면 번쩍임이 더해집니다. 확률은 `src/gear.ts`의 `START_ODDS`에 있습니다. 보스를 쓰러뜨릴 때마다 전직의 제단이 나타나고, 한 단계씩 특성을 키웁니다.

| 단계 | 시점 | 내용 |
| --- | --- | --- |
| 1차 전직 | 5번 방 보스 뒤 | 기본 직업을 고릅니다. 체력, 이동 속도, 무기, 스킬, 모습이 직업에 맞게 바뀝니다. 쓰던 무기는 발밑에 남습니다. |
| 2차 각성 | 10번 방 보스 뒤 | 1차 직업에서 이어지는 직업을 고릅니다. |
| 3차 각성 | 15번 방 보스 뒤 | 2차 직업에서 이어지는 직업을 고릅니다. |

- 제단은 방을 클리어하면 깨어나고, E로 사용합니다. 쓰기 전에는 사다리를 탈 수 없습니다. 전직할 때 최대 체력의 30%를 회복합니다.
- 각성한 직업은 발밑에 직업 색 오라가 생기고, 직업 태그를 세트 효과에 1개로 셉니다.
- 다음 단계 직업이 하나도 정의되어 있지 않으면 그 보스 방에는 제단이 나오지 않습니다.
- 메뉴의 "전직 계보"에서 직업과 각성 갈래, 해금 조건을 볼 수 있습니다.

기본 직업:

| 직업 | 체력 / 이동 | 무기 / 스킬 | 해금 |
| --- | --- | --- | --- |
| 전사 | 130 / 190 | 한손검 / 방벽 | 기본 |
| 궁수 | 95 / 215 | 장궁 / 대시 | 기본 |
| 도적 | 90 / 245 | 단검 / 대시 | 누적 사망 2 |
| 마법사 | 80 / 195 | 화염 지팡이 / 충격파 | 누적 처치 100 |
| 수도승 | 110 / 225 | 건틀릿 / 분노 | 보스 처치 1 |
| 탐험가 | 100 / 210 | 채찍 / 포탑 설치 | 누적 방 클리어 30 |

### 직업 추가하기

`src/content.ts`의 `CHARACTERS`에 항목을 넣으면 됩니다. 예시(2차 각성):

```ts
{
  kind: 'char', tier: 2, id: 'paladin', parent: 'warrior', sprite: 'knight_m', name: '성기사', color: '#ffe08a',
  desc: '화면에 보이는 설명', hp: 20, speed: 0, startWeapon: '', skill: '',
  tag: 'guard', passive: '피해 +20%', apply: (m) => { m.dmg *= 1.2; },
  unlock: { stat: 'bossKills', target: 2 }, // 생략하면 처음부터 열림
},
```

- `tier`: 1(1차 전직), 2(2차 각성), 3(3차 각성). 2와 3은 `parent`에 바로 아래 단계 직업 id를 적습니다.
- `hp`: 1차는 기본 체력, 2/3차는 더할 체력. `speed`는 1차만 씁니다.
- `startWeapon`(`src/gear.ts`의 무기 id), `skill`(스킬 id): 빈 문자열이면 바꾸지 않습니다.
- `tag`: 세트 효과 태그(blade, shot, element, blood, guard, swift). `apply`: `Mods` 수정치(피해, 공격 속도, 치명타, 화상, 독 등)를 바꿉니다.
- `Mods`로 표현할 수 없는 고유 효과(예: 특정 조건에서 확정 치명타)는 `src/game.ts`에서 `this.job.id`로 분기해 넣어야 합니다.

## 아이템 조합

아이작처럼 아이템끼리 엮이도록 세 가지 층으로 조합이 일어납니다.

1. **효과 전파**: 근접, 투사체, 회전 칼날, 폭발, 가시 반격, 번개, 파편 등 모든 피해에 화상, 독, 냉기, 흡혈, 치명타가 똑같이 적용됩니다. 번개나 폭발, 파편이 다시 상태이상을 거는 식으로 효과가 이어집니다. 다른 효과에서 나온 피해는 번개와 파편을 다시 일으키지 않아 무한 연쇄는 생기지 않습니다.
2. **세트 효과**: 아이템마다 태그(칼날, 사격, 원소, 피, 수호, 신속)가 있고, 같은 태그를 서로 다른 아이템 3종으로 모으면 발동합니다.

| 세트 | 효과 |
| --- | --- |
| 칼날 폭풍 | 공격 4번마다 칼날 파편 8개를 흩뿌림 |
| 명사수 | 투사체 관통 +1, 탄속 +30%, 근접 사거리 +20% |
| 원소술사 | 화상/독에 걸린 적이 죽으면 상태이상이 주변으로 옮겨 붙음 |
| 흡혈귀 | 흡혈 +5%, 처치 시 체력 2 회복, 체력 40% 미만이면 피해 +30% |
| 철벽 | 10초마다 피해 1회를 막는 보호막 |
| 질풍 | 이동 속도 +15%, 움직이는 동안 공격 속도 +20% |

3. **조합 시너지**: 특정 아이템 두 개를 함께 가지면 발동합니다. 처음 발동하면 도감에 기록됩니다.

| 시너지 | 아이템 | 효과 |
| --- | --- | --- |
| 화염 폭발 | 화염 부적 + 폭발 구슬 | 폭발 범위/피해 증가, 휩쓸린 적에 화상 |
| 독연 | 독침 + 화염 부적 | 화상과 독이 함께 걸린 적은 지속 피해 2배 |
| 초전도 | 서리 결정 + 번개 병 | 언 적에게는 번개가 반드시 튀고 한 번 더 이어짐 |
| 불꽃 바퀴 | 회전 칼날 + 화염 부적 | 회전 칼날이 크고 빠르게, 피해 1.5배 |
| 피의 가시 | 가시 갑옷 + 흡혈 송곳니 | 가시 반격 피해의 50% 회복 |
| 추적 탄막 | 쌍발 + 유도 깃털 | 투사체 +1, 강한 유도 |
| 튕기는 관통 | 도탄 + 철갑탄 | 벽에 튕길 때마다 관통 +1, 피해 +20% |
| 연쇄 폭발 | 분열 구슬 + 폭발 구슬 | 파편이 닿으면 작게 폭발 |
| 처형 | 치명 렌즈 + 유리 대포 | 치명타 피해 3배 |
| 가속 회로 | 모래시계 + 신속의 장화 | 스킬 사용 후 2.5초간 공격 속도 +50% |

보상 카드에는 태그가 표시되고, 고르면 새 세트나 시너지가 발동하는 카드에는 "발동: 이름" 표시가 붙습니다. 일시정지 화면에서 태그별 진행도(예: 원소 2/3)를 볼 수 있습니다.

## 제약과 보상 아이템

보상과 함께 대가가 붙는 아이템입니다. 보상 카드와 도감에 대가가 붉은 줄로 표시됩니다.

| 아이템 | 보상 | 대가 | 해금 |
| --- | --- | --- | --- |
| 찌르기 교본 | 베기 무기가 찌르기로 바뀜. 피해 +40%, 사거리 +30% | 범위가 좁아지고 적 투사체를 쳐내지 못함 | 기본 |
| 무거운 추 | 모든 근접 무기가 내려치기로. 피해 +50%, 넉백 2배, 넓은 범위 | 근접 공격 속도 -30% | 기본 |
| 회오리 손잡이 | 베기와 내려치기가 360도 회전 베기로 (적 투사체도 사방으로 쳐냄) | 근접 피해 -25%, 근접 공격 속도 -15% | 누적 처치 150 |
| 투척 장갑 | 근접 무기를 던짐(사거리 약 2.6배, 관통 +1). 피해 +20% | 근접 판정이 사라짐, 근접 공격 속도 -20% | 누적 사망 3 |
| 산탄 시위 | 활과 지팡이 투사체 +3발 부채꼴 | 투사체 피해 -45%, 사거리 -40% | 기본 |
| 저격 조준경 | 투사체 속도 2배, 피해 +50%, 관통 +2 | 원거리 공격 속도 -40% | 최고 도달 방 4 |
| 과부하 수정 | 투사체 크기 2배, 맞히면 폭발 | 원거리 공격 속도 -40% | 누적 처치 250 |
| 광기의 가면 | 공격 속도 +45% | 받는 피해 +35% | 기본 |
| 깃털 칼날 | 이동 속도 +20%, 공격 속도 +15% | 근접 사거리 -25%, 피해 -10% | 기본 |
| 고행의 사슬 | 피해 +35% | 모든 회복량 -60% | 누적 사망 5 |
| 거인의 장갑 | 근접 사거리 +50%, 피해 +20% | 이동 속도 -20% | 보스 처치 1 |
| 도박꾼의 주사위 | 치명타 확률 +25%, 치명타 피해 +1배 | 치명타가 아닌 공격 피해 -30% | 누적 아이템 획득 40 |

공격 방식을 바꾸는 아이템을 여러 개 가지면 투척 장갑 > 회오리 손잡이 > 무거운 추 > 찌르기 교본 순으로 우선합니다(예: 찌르기 교본과 무거운 추를 함께 가지면 내려치기, 거기에 회오리 손잡이가 더해지면 회전 베기). 덮어써진 아이템의 피해, 사거리, 공격 속도 보정은 그대로 함께 쌓입니다. 원거리 무기를 든 동안에는 근접용 아이템의 대가(공격 속도 감소)도 붙지 않고, 반대도 마찬가지입니다.

## 에셋

그래픽은 0x72(Robert)의 [16x16 DungeonTileset II](https://0x72.itch.io/dungeontileset-ii) v1.7 시트를 사용합니다(CC0, 출처 표기 의무 없음). 출처와 라이선스는 `src/assets/ASSET_LICENSE.md`에 정리했습니다. 스프라이트 좌표와 애니메이션 프레임 수는 `src/spritesheet.ts`에 있고, 콘텐츠의 `sprite` 값은 그 표의 키입니다. 이 시트에는 투구, 갑옷, 신발, 반지 그림이 없어서, 해당 아이콘은 `src/icons.ts`에 12x12 픽셀아트로 직접 그렸습니다.

보스는 3D 모델로 그립니다. Kay Lousberg의 [KayKit Character Pack: Skeletons](https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Skeletons-1.0)(CC0)를 쓰며, 파수꾼은 도끼와 방패를 든 해골 전사, 군주는 쌍검 해골 도적, 심연의 왕은 지팡이를 든 해골 마법사입니다. 게임 로직은 2D 그대로이고, `src/boss3d.ts`가 Three.js로 보이지 않는 캔버스에 보스를 112px 해상도로 렌더링한 뒤 2D 화면의 보스 위치에 확대해 붙입니다. 그래서 투사체, 이펙트, 조명과의 앞뒤 순서가 다른 적과 같고, 도트 그림과 픽셀 크기가 비슷하게 맞습니다. 등장(땅에서 기어 나옴), 걷기, 공격, 소환, 돌진 준비와 돌진, 탄막 시전, 사망 동작이 게임 상태에 맞춰 재생되고, 피격 시 하얗게 번쩍입니다. WebGL을 쓸 수 없거나 모델을 아직 불러오지 못했으면 기존 2D 보스 그림으로 그립니다. 모델 파일(`src/assets/models/boss1~3.glb`, 텍스처 `skeleton_texture.png`)은 `scripts/pack-boss-models.mjs`로 원본에서 다시 만들 수 있습니다.

## 코드 구조

| 파일 | 역할 |
| --- | --- |
| `src/content.ts` | 직업(전직 계보), 아이템, 스킬 정의와 해금 조건 |
| `src/synergy.ts` | 아이템 태그, 세트 효과, 조합 시너지 정의 |
| `src/gear.ts` | 장비 베이스(무기/방어구/장신구), 등급, 무작위 옵션 |
| `src/icons.ts` | 시트에 없는 방어구/장신구 아이콘(12x12 픽셀아트) |
| `src/meta.ts` | 저장(localStorage), 누적 통계, 해금 판정 |
| `src/game.ts` | 런 시뮬레이션: 플레이어, 적, 투사체, 보스, 보상 생성, 렌더링 |
| `src/adapt.ts` | 적의 적응: 성향 정의(`TRAITS`), 방 기록을 점수로 바꾸는 규칙, 단계별 적응 비율(`ADAPT_LEVEL`) |
| `src/ui.ts` | 메뉴, 해금 도감, 보상 선택, 결과 화면 (DOM 오버레이) |
| `src/boss3d.ts` | 보스 3D 모델 로드, 애니메이션 선택, 2D 화면 합성 |
| `src/spritesheet.ts` | 스프라이트 좌표표 |
| `src/sprites.ts` | 스프라이트 시트 로드, 그리기, 애니메이션, 배경 타일 |
| `src/input.ts` | 키보드/마우스 입력 |
| `src/main.ts` | 화면 전환과 게임 루프 |

새 장비를 추가하려면 `gear.ts`의 `WEAPONS` 또는 `ARMORS`에 항목을 넣습니다. 무기는 `wkind`(베기, 찌르기, 내려치기, 활, 지팡이)로 공격 방식이 정해집니다. 새 아이템을 추가하려면 `ITEMS`에 `apply(m)`로 `Mods`를 수정하는 항목을 넣습니다. 새로운 효과가 필요하면 `Mods`에 필드를 추가하고 `game.ts`에서 처리합니다.
